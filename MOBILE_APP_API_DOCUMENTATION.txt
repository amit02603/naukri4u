================================================================================
                       NAUKRI4U — MOBILE APP API DOCUMENTATION
================================================================================

BASE SERVER URLs:
-----------------
Production Server: https://naukri4u-backend.onrender.com/api/v1
Local Dev Server:  http://localhost:5000/api/v1

AUTHENTICATION HEADER:
----------------------
For all protected endpoints, pass the JWT access token in HTTP header:
Authorization: Bearer <accessToken>
Content-Type: application/json
